# content-label-foundation

**Purpose:** a bounded prerequisite for WP-008 only.

It provides exactly the human labels for Save, Undo, Redo, Previous move, Next move, and Help, plus platform-key formatting. It does not move existing strings, consolidate formatters, add the registry check, or change rendered copy. WP-024 later absorbs the module as part of its full mechanical migration with its original acceptance criteria unchanged.

This is execution metadata only; it is not implementation work and is initially `not-started` in `state.json`.
